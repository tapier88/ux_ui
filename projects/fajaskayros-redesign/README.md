# Fajas Free Kayros — primer rediseño

Rediseño estático inicial para `https://fajaskayros.com/`.

## Qué incluye

- Landing ecommerce responsive.
- Datos originales preservados.
- Productos/precios/categorías visibles del sitio original.
- Enlaces originales a productos, categorías, redes y WhatsApp.
- Formulario visual que deriva a WhatsApp.
- Sin integración Gmail.

## Archivos

- `index.html`: estructura principal.
- `styles.css`: dirección visual premium/ecommerce.
- `script.js`: render de productos y filtros.
- `ORIGINAL_DATA.md`: auditoría de datos preservados.

## Pendiente

El usuario indicó que enviará una referencia visual. Cuando llegue, ajustar:

- paleta;
- composición;
- tipografía;
- ritmo de secciones;
- estilo de cards/productos;
- hero visual.

## Verificación manual

Abrir `index.html` en navegador y revisar:

1. Navegación responsive.
2. Filtros de productos.
3. Enlaces a WhatsApp/redes/productos.
4. Productos y precios contra `ORIGINAL_DATA.md`.
